# Railway Reservation System

## 📝 About the Project
The Railway Reservation System is a beginner-friendly C application that allows users to manage passenger reservation records efficiently. The application provides a menu-driven interface to book tickets, display reservations, search, update, and cancel passenger bookings.

## ✨ Features
- Book passenger tickets
- Display all reservations
- Search reservation by Passenger ID
- Update reservation details
- Cancel reservations
- Simple menu-driven interface

## 🛠️ Technologies Used
- C Programming
- Structures
- Arrays
- Functions
- Menu-Driven Programming

## 🎯 Learning Outcomes
This project helped me learn:
- Working with structures in C
- Implementing CRUD (Create, Read, Update, Delete) operations
- Using functions for modular programming
- Searching and updating records
- Developing menu-driven console applications

A simple C-based Railway Reservation System for managing passenger reservations using structures and menu-driven programming.
